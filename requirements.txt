# Mutual Fund FAQ Assistant (RAG Chatbot) - dependencies

# --- CPU-only torch --------------------------------------------------------
# The default Linux wheel for torch 2.14.0 pulls in nvidia-cudnn / nccl /
# cusparselt / nvshmem + triton - several GB of CUDA on a host with no GPU,
# which either fails the install or blows the deploy's memory budget.
#
# The `+cpu` local-version build exists ONLY on the PyTorch CPU index, so this
# pin forces the CPU wheel while `--extra-index-url` keeps PyPI reachable for
# every other dependency below. `--extra-index-url` rather than `--index-url`
# deliberately: the latter would replace PyPI wholesale and break all of these.
#
# On Render the blueprint installs `torch==2.14.0` from the CPU index first.
# That satisfies this pin too - `==2.14.0` matches `2.14.0+cpu` under PEP 440 -
# so the CUDA wheel is still skipped there and the build is unaffected.
--extra-index-url https://download.pytorch.org/whl/cpu
